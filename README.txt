# SomaBox Digital Library - Installation Guide

Welcome to SomaBox! This portable version allows you to run the digital library on your local device without manual configuration.

## How to Start
1. Extract this folder to any location on your PC.
2. Ensure you have **Node.js** installed (v18 or higher).
3. Double-click the file titled **"Start Somabox.bat"**.
4. Wait a few seconds for the terminal to appear. It will automatically open your web browser to `http://localhost:3000`.

> **Note for Developers**: If you are moving this folder from a **Mac** to **Windows**, the startup script will automatically try to rebuild native modules (like SQLite). This requires an internet connection for the first-time setup on a new operating system.

## First-Run Setup
The first time you run Somabox, it will ask you to:
1. **Set an Admin Password**: This will be used to access the management dashboard.
2. **Configure Cloud Sync**: Choose if you want to sync content from our cloud servers to your device.

## How to Stop
1. Double-click the file titled **"Stop Somabox.bat"**.
2. This will safely close all background services.
